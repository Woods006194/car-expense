云端同步（GitHub Gist）

数据存入你 GitHub 名下的私密 Gist，任何设备联网即可读写，无需开电脑。步骤：
① 打开 GitHub 令牌创建页（需已登录 GitHub；令牌只勾选 gist 权限）→ 点 Generate token；
② 复制生成的令牌（ghp_ 开头）粘贴到下方。令牌仅保存在本设备浏览器中，不会上传到任何第三方。
③ 点"连接云端"：已有云端数据则填数据 ID 后连接；留空则把当前数据新建为云端数据。其他设备用"复制设备接入链接"+粘贴同一令牌即可加入。
